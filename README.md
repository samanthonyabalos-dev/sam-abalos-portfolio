# Sam Anthony L. Abalos — Portfolio Website

A self-contained, responsive HTML portfolio website with a navy palette, dark mode by default with an optional light mode, individual project previews, and category-specific links.

## Preview locally

Open `index.html` in a browser. Google Drive previews require the original files to be shared. YouTube embedded playback generally needs a published HTTPS website; opening the HTML locally cannot always play YouTube.

## Publish with GitHub Pages

1. Create a new public GitHub repository (suggested name: `sam-abalos-portfolio`).
2. Upload `index.html` and this README into the repository's root directory.
3. Go to Settings → Pages → Build and deployment, select `Deploy from a branch`, branch `main`, folder `/(root)`; save.
4. Once GitHub Pages activates, use the published HTTPS address in applications.

## Category-specific URLs

After publishing, share the site URL followed by:

- `#ugc` for UGC and short-form edits
- `#youtube` for long-form documentaries and Peekabeans clips
- `#creative` for AI-generated images and videos

The share buttons on the site copy the exact category URL when accessed on a public HTTPS website.

## Theme

Dark mode is the default for new visitors. Use the Light mode / Dark mode toggle in the header to switch themes; your choice is remembered in your browser.

## External content

Project thumbnails and previews reference Google Drive and YouTube content. Their appearance depends on sharing permissions, connection, and source-platform embedding policies. The Open original link is always available.

## Ownership / permissions

Before publishing the site publicly, confirm that any client footage, unposted edits or other third-party work may be shown in a public portfolio.
